EASY #JS-001 • JavaScript

What is the difference between var, let, and const?

Explore scope differences, hoisting behavior, and re-assignment rules in modern JS.

expand_more

Key Distinctions

  • Scope: var is function-scoped, while let and const are block-scoped.
  • Hoisting: var variables are hoisted and initialized as undefined. let/const are hoisted but in the "temporal dead zone".
  • Re-assignment: const creates a read-only reference; it cannot be reassigned (though objects can be mutated).
// Example of Block Scope
{
  var a = 1;
  let b = 2;
}
console.log(a); // 1
console.log(b); // ReferenceError: b is not defined
MEDIUM #ARCH-008 • Architecture

Explain Micro Front-ends and their implementation.

Breaking down complex UIs into independent, deployable, and scalable modules.

expand_more

Definition & Purpose

Micro Front-ends extend the microservices pattern to the client side. They allow multiple teams to work independently on different parts of a large web application without interference.

Popular Strategies

  • Iframe integration: Simplest but faces isolation and performance issues.
  • Build-time integration: Publishing sub-apps as npm packages.
  • Runtime via Module Federation: Webpack 5's solution for loading remote chunks dynamically.
  • Server-side composition: Edge side includes (ESI) or server-side routing.

Pro-Tip: When asked about this, emphasize the "Trade-offs"—specifically payload size (duplicate dependencies) and consistent UX/styling across teams.

HARD #PERF-012 • Engineering

How would you optimize the Core Web Vitals for a heavy e-commerce page?

LCP, FID, and CLS optimization techniques for high-traffic commerce sites.

expand_more

LCP (Largest Contentful Paint) Optimization

  • Optimize image delivery using AVIF/WebP and CDN edge resizing.
  • Critical CSS inlining to render the above-the-fold content immediately.
  • Resource hinting (preload, preconnect) for hero images and key fonts.

CLS (Cumulative Layout Shift) Prevention

  • Reserve space for dynamic elements (ads, banners) with fixed dimensions or aspect-ratio boxes.
  • Avoid inserting content above existing content unless it's in response to a user interaction.

psychology Business Scenario

Imagine the marketing team wants a pop-up banner on load. How do you balance this with CWV requirements? Mention using "Lazy Hydration" and "Skeleton Screens" as compromises.
